# martin-clean-code

A Claude Code skill extracted from *Clean Code: A Handbook of Agile Software Craftsmanship* by Robert C. Martin.

## What this skill provides

This skill structures the knowledge from *Clean Code* into an agent‑usable format:
- Named frameworks (Boy Scout Rule, Intention‑Revealing Names, Small Functions, etc.)
- Actionable principles and techniques
- Anti‑patterns to avoid
- Decision rules and quick‑reference cheatsheets

## How to use

Once installed, invoke the skill by name:

```bash
martin-clean-code
```

To get help on a specific topic:

```bash
martin-clean-code about naming
martin-clean-code about functions
martin-clean-code for ch03
```

## Installation

With the Agent Skills CLI (compatible with Claude Code, GitHub Copilot CLI, Amp, etc.):

```bash
npx skills add https://github.com/thewhite2255dev/martin-clean-code-skill.git --skill martin-clean-code
```
